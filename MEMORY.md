# MEMORY

Przed dalsza praca przeczytaj `EXECUTIVE_PLAN.md`, bo jest sledzonym zrodlem aktualnego kierunku projektu i nastepnych zadan. RTS Nano ma isc w strone pelnej funkcjonalnie gry RTS w stylu WarCraft II, ale z lekka, deterministyczna symulacja headless pod trening wielu instancji sieci neuronowych. Core gry nie powinien zalezec od Pygame, PyTorch, Gymnasium ani ciezkich integracji; takie rzeczy maja trafiac do adapterow. Obecny etap ma kolejki produkcji, budowe Barracks i House przez workerow, cancel construction z refundem, UI placement, stop/hold/attack-move/return cargo orders oraz population cap liczony z ukonczonych budynkow; nastepny wazny kierunek to command panel/hotkeye, gather UI i dalsze testy headless/env przy kazdej mechanice.
